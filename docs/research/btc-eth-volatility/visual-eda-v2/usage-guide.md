# V2 人工研究使用指南

## 推荐顺序

1. **Price & Trend：Price + Slope**。选15m，再对照5m/60m，判断速度与尺度依赖；变化减速不是反转预测。先看10/29–30，再对照固定末段。
2. **Cross-Asset：Correlation + Beta**。用固定60/240/1440m，查看光标处配对数量/覆盖率，判断关系是否随窗口变化。高同期相关不证明BTC领先。
3. **Residual + Z**。H03残差只用排除signal60的历史beta，Z基准排除当前。观察异常是否与beta再估计、缺口、活跃状态同时发生。±2不是入场阈值；动态残差不是平稳价差。
4. **Execution & Quality：Spread + Cost**。先单腿，再看总gross加权双腿预算；区分不同名义分母。9bps/边手续费和5bps/边滑点仅预算，实际费率未知。历史偏离超过预算也不等于未来可成交净利。
5. **Events & Distribution（事后）**。在同一UTC范围选择冲击方向、分布/对齐路径/散点/固定时滞/热图/尾部。个别事件可悬停UTC；均值/中位数/IQR不是独立样本推断。

## 操作

- 四个标签给出默认组合；勾选辅助图最多四张，主价格图始终保留。BTC/ETH选择只影响单资产图；Cross-Asset配对指标始终需要两资产。
- 上方UTC输入和固定研究窗口控制所有时序图；固定日切分为半开区间，页面显示实际最后一分钟。拖动任一时序图缩放，双击或“完整历史”恢复。
- 悬停移动共享光标，点击固定/解除固定；画布聚焦后左右箭头移动一分钟。侧栏滑块也可选历史时点。右栏只有过去/当前；事后视图明确隔开。
- A保留新有效事件的零收益；B严格活跃报价。价格本身相同，窗口资格不同；B常出现大片MISSING，尤其Z历史不足时全空，这是真实覆盖限制，不能降低门槛补图。
- 灰色热图格表示无有效观测；选择ETH绝对收益、Spread或收益覆盖率，悬停看该UTC日/小时明细。未来收益与事件对齐路径均为事后观察。
- 点击“原版五组图”打开冻结V1：价格、分钟收益/质量标记、RV、冲击分布、质量/成本。所有原始PNG可直接打开，不需要HTML脚本。

## 读图限制

全样本仅约15天，已被多次研究。来源是PAS Testnet异步分钟REST，不是逐笔成交/连续盘口；不会生成OHLC、Footprint、CVD或虚构秒级路径。没有新增Funding/Oracle/depth图，PR38补充源不覆盖全段。

窗口缩放和界面选择属于探索，不产生新的样本外验证。候选机制需要新方案与新证据；本工具不自动检验。PR38普通Lead–Lag与相对回归的已有不利/不确定结果仍有效。
