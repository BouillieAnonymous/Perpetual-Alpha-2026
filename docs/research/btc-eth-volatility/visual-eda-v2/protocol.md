# V2 fixed visualization definitions

2026-11-04. Descriptive research terminal only. No hypothesis tests, predictions, parameter optimization, backtests or production changes. Keep V1 / PR38 immutable. Inputs: SHA256-pinned Stage1 raw and causal panel, PR36 V1 reviewed Dashboard, PR38 points and manifest at fixed heads. All history observed; no clean OOS.

- A preserves valid fresh-event zero returns; B requires changed top prices and 30–90s event spacing. No filling/interpolation or partial cumulative-return/RV windows.
- Slope5/15/60: OLS log(Mid) on integer UTC minutes 0…w, w+1 prices; all w returns must satisfy selected A/B. bps/min = slope*10000. No dollar slope comparison.
- Corr/Beta60/240/1440: clock windows [t-w+1,t], only jointly valid signed minute-return pairs. Require full nominal clock history, at least ceil(.9*w) pairs, and each centered sum of squares >1e-18 raw-log-return squared. Show n/w, missing reasons. Pearson and Cov(ETH,BTC)/Var(BTC), not causality. Pairwise deletion is an explicit covariance estimator, never price/return filling.
- H03 Beta: exactly PR38 [i-1500,i-60) 1440 historical returns, n>=1296 and BTC centered sum of squares>1e-18. Excludes signal60m, ends before it. Recompute and compare every PR38 beta/count/past60/residual. H03 relative residual60 = ETH past60 - H03 beta*BTC past60, bps; no intercept subtraction, no executable portfolio return.
- Z: compare current H03 residual60 against residuals [i-1440,i), excludes current; full clock history and >=1296 finite residuals. Sample standard deviation ddof=1, sd>1e-6 bps; otherwise missing. Reference lines ±1/±2 only, never orders. Overlapping residuals are dependent.
- RV ratio: ETH RV15/60 divided by BTC RV15/60; complete selected-mode windows, denominator>1e-12 bps. Not regime forecast.
- Costs: PR38 configuration budgets fee9 bps/side, slippage5 bps/side. Single-leg round-trip = current full spread +18 +10 bps. Two unweighted legs = spreadBTC+spreadETH+36+20 bps in per-leg-notional basis. H03 gross-normalized weighted two-leg spread = (spreadETH+abs(beta)*spreadBTC)/(1+abs(beta)); fee+slip28 bps on total gross. Same-mid, frozen-spread scenarios; actual rates/fills/legging/Funding unknown. Residual/(1+abs(beta)) is only a historical movement magnitude comparator, not executable payoff. No net field.
- Scatter uses selected past/current range; line is descriptive in-range OLS, explicitly not as-of feature. Fixed lags {-30,-15,-5,-1,0,1,5,15,30}; corr(BTC_t,ETH_{t+lag}), positive lag uses later ETH and is retrospective only. No best-lag search. UTC hour heatmaps, distributions/Q01/Q05/Q50/Q95/Q99 and event paths all retrospective.
- Event paths: reuse V1 fixed development Q05/Q95 BTC1m events (no future selection), BTC/ETH signed cumulative path anchored t=0 for offsets -15…+30, complete intervening returns; no gap bridge. All events retained; pointwise median/IQR counts and individual selection. A/B affects path availability only, never event membership. No IID or confidence bands.
- All temporal hover sidebar fields are past/current only. Future5/15/30 are exposed only in Events retrospective pane. Plot range/asset/mode/window UI choices are exploratory, never validation.
