## 6. 我们正在运行的 Funding-LAST 说明什么

PAS 账本：11 个决策、1 个 terminal intent；当前持有 0.0103 ETH，入场均价 2406.9，最新 mark 2313.1，名义约 23.82 USDP。账户一致性检查为 true，未暂停、无 market_wait。最新观察权益约 99,999.33252，对初始 100,000 差额约 -0.66748 USDP（-0.00066748%）。这是本地观察权益差额，不是已独立完成转账/资金费/手续费全历史归因的正式比赛收益。

小额执行预算约 25/100000=0.025% 账户权益。即使这笔名义仓位赚 4%，对账户也只有约 0.001% 收益贡献。因此与榜单几个百分点的账户收益直接比较，会把资本使用率差异混入策略质量。当前是执行观察的规模；是否扩大额度是另一个决定，现有证据不支持因为落后榜单就放大仓位。

当前仓位未实现损益约 -0.96614 USDP。资金费/费用等会使账户差额与其不同，但本次没有将 cumFunding 字段直接解释为到账收益，也未据此宣称完成归因。只有一笔 intent，不能估计胜率、换手稳定性或多次调仓能力。

## 7. 队友 Agent：研究价值和合并问题分开看

已定位 #31：nopperab0 的 zs 分支，head ff82523f33dc8acb8237975635f7160b885fe948；open、未合并、mergeable=false，91 文件、12,782 行增加、4,008 行删除。

设计是八类规则候选 → 成本预筛 → Jev Choice 分布 → Top-p 概率门控/仓位权重 → 风险限制 → 下一有效报价 Paper 成交。包含 NO_TRADE、持有期、调仓带、配对篮子、可选探索等。Jev 负责选择已有候选，不直接证明各候选有交易优势；Choice 概率也未被证明等同盈利概率或合理资本权重。

调参文档报告：原基线 638 笔成交、期末平仓后约 -96.3154 USDP；三轮依次约 -7.5513（36 笔）、-1.4346（14 笔）、-0.8954（4 笔）。最后一轮价格毛收益 -0.12164、价差/滑点成本 0.27888、手续费 0.50619、Funding +0.01126 USDP；最后八小时约 -1.54727 USDP。未扣 API 费用，未模拟深度冲击或部分成交。这些是提交文档声明，本次未独立复现。

这主要支持“减少过度调仓能显著减亏”，尚不支持“模型找到正 Alpha”。两次完整持仓无法评价选择能力；同一批历史反复三轮调整，末八小时也不能继续称作独立样本外。文档有尚未真实调用 Jev 的早期说明，也有调参 API 成功次数记录，需要通过冻结请求/响应和对应版本澄清各阶段证据。

## 8. 下一轮研究顺序

1. **冻结七天快照和旧方案。** 记录最大 seq、源码/配置 hash、metadata 与实际可得时间；资金费按事件去重。此轮聚合读的是活库，不是交易一致回测快照；不可直接将本文件当作已封存完整输入。
2. **建立同口径基线。** 同一 PAS panel、同一成本、同一风险预算，比较空仓、固定多/空、Funding-LAST、少量冻结趋势规则。分别报告价格毛收益、价差、费用、滑点、资金费、名义风险收益及账户收益。
3. **独立检查 Agent 增量。** 在固定候选和退出规则下，比较单策略、固定权重、Python router、捕获 Jev 分布；先关闭探索。候选池本身的收益和路由的收益分别归因，包含 API 费用、延迟与失败。
4. **将 10-21 以后作为候选新增段。** #31 文档数据止于 10-20 20:51 UTC；只有核实队友未再用后续数据调参，后段才可能保留验证价值。本次已查看全周市场汇总，因此也需披露这次查看；真正前瞻应从新冻结方案后的未来数据开始。
5. **通过独立 shadow 记录未来表现。** 不因榜单正收益改变规则或放大资金。先积累足够独立持仓并验证成本后增量，再决定运行接入和预算。
